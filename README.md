# guides
Авторские путеводители по местам где я был

## Сайт

[План побега — путеводители Антона Эльстона](https://antontravel.github.io/guides/)

Статический сайт: `index.html`, `style.css`, `motion.js` и папка `assets/`.
GitHub Pages публикует ветку `main`, папку `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll.

Пути к стилям, скрипту и изображениям относительные, поэтому сайт работает в `/guides/`.
Социальные ссылки, фотостикеры, орнаменты, параллакс и настройки уменьшения движения сохранены.
Источники и лицензии фотографий для стикеров указаны на странице и в `assets/release-sticker-sources.json`.

## Путеводители PDF

PDF хранятся в папке `downloads/` этого репозитория и доступны через GitHub Pages:

- [Плёс для телефона, 36 страниц, 7,9 МБ](https://antontravel.github.io/guides/downloads/ples-phone.pdf).
- [Плёс для печати A5, 19,4 МБ](https://antontravel.github.io/guides/downloads/ples-print-a5.pdf).

Кнопки сайта используют относительные ссылки на эти файлы. Для обновления путеводителя замените соответствующий PDF в `downloads/` и сохраните изменения в `main`.

## Обновления

Правки в `main` запускают автоматическую публикацию Pages.
Проверять результат во вкладке Actions и по адресу сайта.
